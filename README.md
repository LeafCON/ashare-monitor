# A股 / 港股 / 美股行情监测台

[English](README.en.md)

本机桌面程序，覆盖 A 股、港股、美股和加密货币。自选、行情、持仓、告警、量化策略和交易接口都在同一个窗口里。密钥只写在这台电脑的 `.env`，页面上只显示末四位。某个市场还没配交易接口时，那一路等待，不发单。软件不会去点交易客户端，也不会保存交易软件的登录密码。

界面可以在中文和 English 之间切换，也可以跟随系统、浅色或深色。

## 页面

### 看板

搜索代码或名称加入自选。交易决策一栏显示四个市场是否已接上接口，以及当前用的决策模型。下面是总资产、现金和股票市值。总资产以美元计，并附人民币约数。行情分美股、港股、A 股，点一行打开走势。

![看板](docs/screenshots/board-zh.png)

英文界面同一页：

![Board](docs/screenshots/board-en.png)

### 持仓

可以按股数记，也可以按金额记。基金没有股数、券商里的碎股，都用金额或小数股数保存。同一代码再次保存会覆盖这条持仓，不改现金余额。

「让 AI 填写」接受交易界面截图。DeepSeek 只填密钥；其他服务再填地址和模型名。也可以改用本机已经在跑的模型。把图片拖进窗口，或点区域选择文件。识别过程会列出步骤，识别到的持仓直接写入下面的列表。

汇总卡和持仓行使用同一种货币。只有人民币持仓时，上面显示人民币；同时有美元或港币时，汇总先换成人民币，再附一行等值美元。

![持仓与截图识别](docs/screenshots/holdings.png)

### 监控预警

没填写跌破价、突破价、止损价或涨跌幅阈值的股票只显示行情，不发告警。策略命中后走 Telegram。分区视图和卡片视图可以切换。「只打印」不请求 Telegram，「真发 Telegram」用来单独测试发送。

自动下单默认关闭。关闭时只提醒，文案带「请手动确认」。打开后也不会点击交易软件，不会保存交易密码；对应市场没有券商接口时，不会提交委托。

![监控预警](docs/screenshots/alerts.png)

### 量化

手写条件：名称、代码、命中后的标记，以及 PE 分位、ROE 这类条件。也可以把一段策略说明贴进文本框，用已配置的接口提取成条件。还没有信号数据时，点「拉取最新数据」。

![量化](docs/screenshots/quant.png)

### 接口

Telegram、加密货币和股票券商分卡填写。已保存的密钥只显示末四位，留空表示不修改。没填的市场保持「等待接口」。决策模型可以选本机已运行的服务，或另填一套 API。

![接口](docs/screenshots/apis.png)

侧栏里还有告警历史、交易记录、现金和财报。现金按美元、人民币账户分开。交易记录可以导出 CSV。

## 功能说明

- **自选。** 看板上搜索 `600519`、茅台、`00700`、腾讯或 `AAPL` 后加入。`600519` 记为 `600519.SS`，`000001` 记为 `000001.SZ`，`00700` 或 `700` 记为 `00700.HK`，美股保持字母代码。加入自选只显示行情，不自动建立告警。
- **行情。** A 股先用新浪，失败再用腾讯。港股、美股和指数卡用东方财富。指数卡包括标普 500、纳斯达克、道琼斯和美元指数。刷新间隔在 `config.yaml` 的 `monitor.interval_active`，单位是秒。
- **持仓。** 股数可以是小数。金额持仓不要求股数。截图识别和手工录入写进同一张表，可以改、可以删。
- **告警。** 同一条规则有冷却时间，默认 60 分钟。全天默认不超过 30 条。这两项在 `config.yaml` 的 `alert.cooldown`（秒）和 `alert.max_per_day`。`ALERT_DRY_RUN=true` 时，后台触发的告警只打印；看板上的「真发 Telegram」仍会真的调用 Bot API。
- **决策。** 四个市场共用一套闸门。接口没配好就等待。配好之后，通过闸门的决策按该市场的接口发单。本机模型连不上时，状态里会看到当前实际用的后端。
- **界面。** 左侧栏切换页面。底部可切换语言和主题。

首次启动会放入示例 A 股：贵州茅台、五粮液、中国平安、招商银行、平安银行、宁德时代、比亚迪、紫金矿业、沪深300ETF，以及腾讯、阿里巴巴、小米。

告警文案例子：

```
[信号] 600519 贵州茅台 现价1688.00 涨跌+1.23% | 规则:pct_change>=3 | 分组:A股 | 请手动确认 | 时间:2026-10-18 23:41:00
```

## 安装

需要 Windows、Python 3.11+ 和 Node.js。

```bat
copy .env.example .env
copy config.example.yaml config.yaml
```

`.env` 里填写 Telegram。不要把 token 发到聊天里，也不要把 `.env` 提交到仓库：

```
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
TELEGRAM_THREAD_ID=
ALERT_DRY_RUN=true
TRADING_AUTO_ORDER=false
```

普通聊天把 `TELEGRAM_THREAD_ID` 留空。只有 Forum 话题群才需要填写。

Telegram 机器人在 `@BotFather` 创建。给机器人发一条消息后，个人 chat id 可以从 `@userinfobot` 查看，群 id 一般是负数。这些也可以直接在「接口」页填写，保存后写入本机 `.env`。

## 打开

桌面快捷方式 **A股监测台** 打开自己的窗口，不跳到浏览器。

第一次如果缺少依赖，在项目目录双击 `start.bat` 安装，然后再打开快捷方式。

截图拖进窗口只在这个桌面窗口里生效。识别用的是「让 AI 填写」里配置的接口或本机模型。
